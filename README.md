# Autoclicker

A simple, easy to use autoclicker that I made for myself. Feel free to use it or redistribute as mentioned in the license. 
Built with PySide6.

## Features

Autoclicker: self explanatory.
Profile System: set profiles on what action you want to do. (WIP)
Advanced Customization: set the delay, repeat amount, and much more. (WIP)

## Install

### 1. Clone the repository:
```bash
git clone https://github.com
cd your-repo-name
```

### 2. Create .venv:
For mac/linux
```bash
python3 -m venv venv
source venv/bin/activate
```

For windows
```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage
You can launch it through the cmd line, or by downloading a prebuilt release from the Releases page (when available).
```bash
python main.py
```
